## English

This repository is the central catalog for XenForo add-ons developed by Warext Studios. You can quickly access each add-on's source code, current version, installation packages, and project page from the links below.

> **Version** information is maintained according to each add-on's current GitHub repository and published packages.

This is **not** a XenForo installation/runtime compatibility certification; licensed XF 2.3.13 integration tests remain necessary.
